# Job Match Analyser

An AI-powered tool that analyses how well your CV matches a job description — identifying keyword gaps, scoring your fit, suggesting CV improvements, and generating a tailored cover letter opening.

![HTML](https://img.shields.io/badge/Frontend-HTML%2FCSS%2FJS-orange) ![AI](https://img.shields.io/badge/AI-Claude%20Sonnet-6366f1) ![License](https://img.shields.io/badge/License-MIT-green)

---

## What It Does

Paste a job description and your CV — the AI returns:

- **Match score** (0–100) with an animated ring that changes colour based on fit
- **Verdict** — Strong / Good / Partial / Weak match with a plain-English summary
- **Keywords you already have** — skills from the job description found in your CV
- **Missing required keywords** — gaps you should address before applying
- **Nice-to-have skills missing** — bonus areas worth developing
- **CV improvement suggestions** — specific, actionable changes tailored to the role
- **Cover letter opening** — a personalised 3–4 paragraph draft, ready to copy

## How to Use

### Option 1 — Open directly in browser
```
1. Download job_match_analyser.html
2. Open it in any modern browser (Chrome, Firefox, Edge)
3. Paste a job description on the left, your CV on the right
4. Click "Analyse Match"
```

> ⚠️ The AI features require an active Anthropic API connection. The tool is designed to run inside environments that proxy the Anthropic API (e.g. Claude artifacts). To run it standalone, add your API key to the fetch headers in the script.

### Option 2 — Self-host with your own API key
Replace the fetch call in the script with your own key:

```javascript
headers: {
  "Content-Type": "application/json",
  "x-api-key": "YOUR_ANTHROPIC_API_KEY",
  "anthropic-version": "2023-06-01"
}
```

> Never commit your API key to a public repository.

## How It Works

```
User pastes job description + CV
          ↓
Structured prompt sent to Claude Sonnet via Anthropic API
          ↓
AI returns JSON: score, verdict, matched/missing keywords,
                 CV suggestions, cover letter draft
          ↓
Frontend parses JSON and renders:
  - Animated SVG score ring
  - Colour-coded keyword tags
  - Actionable suggestion list
  - Copyable cover letter
```

---

## The AI Prompt Design

The tool uses a structured JSON-output prompt that instructs the model to:

- Score the match honestly (not optimistically)
- Identify **specific** skills and tools from the job description
- Separate required vs nice-to-have gaps
- Generate cover letter content that is **personal and specific**, not generic

Prompting the model to return strict JSON (no markdown, no preamble) and parsing it client-side keeps the tool fast and fully frontend.

## Why I Built This

Job hunting involves reading dozens of listings and trying to figure out how well you fit each one — a time-consuming and often unclear process. This tool automates the analysis, so instead of guessing, you get a data-driven breakdown of exactly where you stand and what to do about it.

It also demonstrates:
- Practical use of the Anthropic Claude API from the browser
- Structured prompt engineering for reliable JSON output
- Parsing and rendering AI responses dynamically in vanilla JS
- Building tools that solve real problems rather than toy demos

## ⚠️ Note on AI Output

The analysis is generated by an AI and should be used as a guide, not a definitive judgement. AI can miss context, misread jargon, or rate things differently than a human recruiter would. Use the output as a starting point for your own thinking, not as a final verdict.
